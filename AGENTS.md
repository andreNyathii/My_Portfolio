# Agent Guidelines

## Tech Stack
- Frontend: React (via Vite)
- Styling: Plain CSS. Do not use Tailwind or external component libraries unless explicitly asked.

## Design Rules
- Rely on the CSS variables defined in `index.css` for colors, fonts, and spacing.
- Keep the aesthetic modern (dark mode, glassmorphism, clean typography).
- Keep components modular and focused.

## Workflow
- Stick to standard React best practices.
- Use semantic HTML tags.
- Update `CHANGELOG.md` when making notable structural changes or adding features.
